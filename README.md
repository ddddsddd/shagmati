# ♞ Шахматы против нейросети

Шахматы в браузере (HTML/CSS/JS + Python), где соперник — нейросеть Claude.
ИИ выбирает ходы, комментирует **свой** ход и **твой**, болтает в чате и умеет
разговаривать голосом в «режиме звонка».

- 🎲 **Жребий**: цвет фигур в каждой партии определяется случайно
- 🤖 **ИИ-соперник** живёт в отдельном API-сервере `ai_server.py`
- 💬 **Комментарии** к каждому ходу и чат с ИИ (можно писать и ходы: `e2e4`, `Nf3`, «конь на f3»)
- 🔊 **Озвучка**: ИИ проговаривает комментарии голосом
- 📞 **Режим звонка**: ИИ говорит и слушает тебя. Микрофон **сам не включается** —
  жми кнопку 🎙️ или зажимай `Пробел` как рацию. Голосом можно делать ходы: «е2 е4», «рокировка»
- ⚙️ Настройки: характер ИИ (дружелюбный / трэштокер / тренер), сила игры, голос, скорость речи

## Как устроено

```
браузер (static/)  ──►  server.py :8000  ──►  ai_server.py :8001  ──►  Claude API
 доска, чат, голос       партия, проверка        выбор хода,
                         ходов (python-chess)    комментарии, чат
```

- `server.py` — игровой сервер: отдаёт сайт, хранит партии, проверяет ходы, бросает жребий.
- `ai_server.py` — сервер нейросети: получает позицию, просит Claude выбрать ход
  (строго из списка допустимых) и написать комментарии.
- Без ключа API `ai_server.py` переключается на простой встроенный движок, так что
  поиграть можно и офлайн (но без умных комментариев и чата).

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

Ключ Claude API берётся на https://platform.claude.com/ и задаётся переменной окружения:

```bash
# Windows PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-..."
# Windows cmd
set ANTHROPIC_API_KEY=sk-ant-...
# Linux / macOS
export ANTHROPIC_API_KEY=sk-ant-...
```

## Запуск

Два сервера в двух окнах терминала (ключ должен быть задан в окне с ИИ-сервером):

```bash
python ai_server.py     # окно 1 — нейросеть, порт 8001
python server.py        # окно 2 — игра, порт 8000
```

Потом открой **http://127.0.0.1:8000** в Chrome или Edge.

Или одной командой: `start.bat` (Windows) / `./start.sh` (Linux/macOS).

## Голос

- Озвучка и распознавание речи — встроенные в браузер (Web Speech API), ничего ставить не надо.
- Распознавание речи работает в **Chrome и Edge** (в Firefox — только озвучка).
- При первом нажатии на микрофон браузер спросит разрешение — разреши.
- Открывай игру именно по `http://127.0.0.1:8000` или `http://localhost:8000` —
  на других адресах без https браузер микрофон не даст.

## Настройки через переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ Claude API |
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель нейросети |
| `AI_OFFLINE` | — | `1` — играть встроенным движком без нейросети |
| `AI_FALLBACKS` | `1` | `0` — отключить запасную модель на случай отказа основной |
| `AI_PORT` | `8001` | порт ИИ-сервера |
| `PORT` | `8000` | порт игрового сервера |
| `AI_SERVER_URL` | `http://127.0.0.1:8001` | где игровой сервер ищет ИИ-сервер |

Сила игры в настройках управляет тем, сколько нейросеть «думает» (effort `low` / `medium` / `high`):
на «Мастере» ходы сильнее, но ждать дольше и запрос стоит дороже. Каждый ход ИИ — один запрос к API.
